# Furstrap

**THIS BOOTSTRAPPER IS ENTIRELY VIBECODED**

this is my personal bootstrapper, I will not be updating this github often because this is semi-public.

this bootstrapper uses FISHSTRAP and EXPLOITSTRAP in 99% of cases.

features:
- like 40 themes
- all allowlist fflags
- serverbrowser
- version manager
- deployment history
- fast loading times (faster than fishstrap)
- global settings
- loads of customizable features

  i will be accepting very few things in the issues tab as this is ment for myself.

  this will not be open source because im lazy.
